# I2NSF Policy Generator

**Fall 2025 · SKKU Data Modeling for Intelligent Networks and Security (ESW7002) · Group 2 Project**

## Overview

This repository documents a team project conducted for **Data Modeling for Intelligent Networks and Security (ESW7002)** at Sungkyunkwan University.

The project develops a security policy generation system for the **I2NSF (Interface to Network Security Functions) framework** using a reasoning LLM. Natural-language security intents are converted into structured XML security policies and validated against the I2NSF policy schema.

The system combines a Python-based LLM backend with a Next.js web interface for interactive intent input and generated-policy display.

## System

- Natural-language security intent input
- Reasoning LLM-based security policy generation
- I2NSF XML policy construction
- XML/XSD-based policy validation
- Python backend
- Next.js web interface
- Benchmark and evaluation utilities

## Technologies

- Python
- Next.js
- TypeScript
- XML / XSD
- OpenAI API
- I2NSF
